# Потерянный багаж

Мобильная игра на Flutter: скупаешь невостребованный багаж на аукционах аэропорта, распаковываешь, проверяешь находки и перепродаёшь.

## Как скачать APK

Открой вкладку **Releases** справа на странице репозитория и скачай файл `.apk` из последней сборки. На телефоне разреши установку из неизвестных источников.

Каждый пуш в `main` автоматически собирает новую версию через GitHub Actions.

## Как играть

- Каждый день на торгах 4–6 лотов: рюкзаки, сумки, коробки, чемоданы, позже алюминиевые кейсы и контейнеры.
- Подсказки: город вылета, вес, бирки. Рентген показывает, что внутри, но не подлинность.
- Торги в реальном времени против четырёх перекупщиков с разными характерами.
- Находки на складе: экспертиза подлинности, ремонт, продажа скупщику или выставление на площадку.
- Покупатели приходят ночью. Непроверенную подделку, проданную как оригинал, могут вернуть.
- События: находятся владельцы вещей, приходят коллекционеры, звонит производитель прототипа.
- Улучшения: стеллажи, рентген, мастерская, оценщик, интернет-магазин, второй склад, фургон.
- Цель — капитал в 1 000 000 ₽.

## Сборка вручную

```
flutter create --project-name lost_luggage --org com.kston --platforms=android .
flutter pub get
flutter build apk --release
```
